# iEat — приложение доставки еды

Адаптивное веб-приложение для Худжанда: каталог ресторанов и блюд, поиск,
категории, сортировка, избранное, корзина, регистрация и вход, профиль,
оформление, история, отмена и повтор заказов, заявки ресторанов.

## Запуск

Нужен Python 3.10 или новее. Внешние зависимости для приложения не требуются.

```bash
cd /workspace/iEat
python3 server.py
```

Сервер использует порт `8000`. Можно задать `PORT=8001 python3 server.py`.
База автоматически создаётся в `data/ieat.sqlite3`; для другой базы задайте
`IEAT_DB=/absolute/path/ieat.sqlite3`. База и аккаунты не попадают в Git.
Не запускайте сайт через `file://` или Live Server: функции используют API.

## Проверки

Автоматические проверки API запускают собственный сервер с временной базой:

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Проверка браузера требует Playwright и Chromium, а также работающий сервер:

```bash
python3 tests/smoke.py
```

Она создаёт тестовый аккаунт, заказ и заявку в базе запущенного сервера.
Для изоляции запускайте сервер с `IEAT_DB=/tmp/ieat-smoke.sqlite3` и отдельным `PORT`.
Адрес сервера для теста задаётся через `IEAT_URL`.

## Хранение и правила

- Аккаунты и заказы хранятся в SQLite. Пароли хешируются scrypt с уникальной солью.
- Сессия хранится в HttpOnly cookie, действует семь дней. Выход удаляет её на сервере.
- История и отмена доступны только владельцу заказа. Цены и доставка рассчитываются сервером.
- Доставка — 15 сомони, бесплатно при сумме блюд от 150 сомони.
- Корзина и избранное сохраняются в localStorage. Не более 20 порций одного блюда.
- Изображения и шрифты локальные/системные, внешние ресурсы не нужны.

## Границы текущей версии

Это функциональный тестовый сервис, а не запущенная служба доставки.
Каталог демонстрационный, ресторан и курьер не получают заказы; оплата не списывается.
Заявки партнёров сохраняются в SQLite и не отправляются менеджеру.
Нет панели оператора, сброса пароля, отправки email/SMS или отслеживания курьера.
Для коммерческого запуска нужны реальные партнёры, провайдер оплаты и уведомлений,
HTTPS и производственный сервер вместо стандартного Python HTTPServer,
резервное копирование, мониторинг и операционная панель.

## Структура

- `server.py` — API, авторизация, SQLite и сервер локальной разработки
- `index.html`, `css/style.css`, `js/app.js` — интерфейс
- `images/` — локальные SVG-иллюстрации
- `tests/` — проверки API и пользовательских сценариев
