# iEat — Food Delivery Website

Готовая стартовая версия красивого сайта доставки еды.

## Запуск в VS Code на Windows
1. Откройте папку `iEat` в VS Code.
2. Откройте `index.html`.
3. Запустите через Live Server или просто откройте `index.html` в браузере.

## Структура
- `index.html` — главная страница
- `css/style.css` — дизайн и адаптивность
- `js/app.js` — рестораны, блюда, фильтры и корзина
- `images/` — папка для будущих изображений
