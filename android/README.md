# iEat Android — автономная тестовая версия

Android 8.0 и новее. APK включает интерфейс, иллюстрации и каталог; интернет и
Python-сервер не требуются. WebView использует локальные ресурсы по внутреннему
HTTPS-адресу, API реализован на Java и SQLite через ограниченный JS-мост.

Аккаунты, заказы и заявки партнёров хранятся только на устройстве и не
синхронизируются с веб-сервером. Пароли защищены PBKDF2-HMAC-SHA256 с уникальной
солью и 120000 итераций. Корзина и избранное сохраняются в WebView localStorage.
Удаление приложения удаляет локальную базу. Приложение не запрашивает сетевые
разрешения, не отправляет заказы и не принимает оплату.

## Сборка в этой облачной среде

```bash
python3 android/tools/setup.py
bash android/build.sh
```

Нужны Python 3, Java 21, keytool, zip и unzip. Скрипт подготовки скачивает
официальные Android Platform 35 и Build Tools 35.0.0, а также Eclipse ECJ
3.40.0 с Maven Central. TLS и контрольные суммы проверяются. Инструменты
хранятся вне репозитория в `/workspace/android-toolchain`.

Результат: `/workspace/artifacts/iEat-1.0.0-debug.apk`.
Переменные `IEAT_TOOLCHAIN` и `IEAT_APK_OUTPUT` меняют эти каталоги.

Это сборка для разработки: включена отладка WebView, APK подписан автоматически
созданным development-ключом вне репозитория. Такой ключ не подходит для
публикации в Google Play. Сохраните ключ вне Git, если нужны обновления с той
же подписью. Для коммерческой версии нужны отключение отладки, собственный
release-ключ, реальные сервисы заказов и оплаты.

## Проверка на эмуляторе

На отдельном Android-эмуляторе с установленными SDK platform-tools и Python
`websockets` выполните `python3 android/tests/smoke.py`. Скрипт устанавливает APK,
очищает **только данные приложения в эмуляторе**, затем проверяет регистрацию,
вход, оформление и отмену заказа, профиль и заявку партнёра через WebView.
Не запускайте его на реальном телефоне с пользовательскими данными.
